# Quiz Application - Questify

![App Logo](quizapplogo.png)

Questify is a feature-rich quiz application built with Java and Tkinter for the GUI. It allows users to test their knowledge across various categories by fetching questions from the Open Trivia Database API.

## Features

- 🎯 **Multiple Quiz Categories**: Choose from a wide range of topics
- 📊 **Score Tracking**: Keep track of your progress and high scores
- 🏆 **Leaderboard**: Compete with other users
- 🔒 **Secure Authentication**: Encrypted user credentials
- 📈 **Progress Visualization**: View your improvement over time with charts
- 🔊 **Sound Effects**: Audio feedback for correct/incorrect answers
- ✉️ **Email Verification**: OTP-based signup and password recovery
- ⚙️ **Customizable Quizzes**: Select difficulty and number of questions

## Technologies Used

- Java
- Tkinter (for GUI)
- Open Trivia Database API
- Cryptography (for password encryption)
- Matplotlib (for progress visualization)
- Pygame (for sound effects)
- SMTP (for email functionality)
